# Project 20/10: Món Quà Công Nghệ & Tinh Tế Dành Cho Tiểu My

## 1. Giới thiệu
Dự án Web App tương tác đặc biệt nhân dịp 20/10 (Ngày Phụ nữ Việt Nam) được thiết kế và "may đo riêng" (bespoke) 100% cho **Tiểu My** từ **Công Lệnh** (Software Engineer).

## 2. Mục tiêu & Tâm lý tiếp cận
- **Tâm lý & Dating Coach:** Tinh tế, ấm áp, hóm hỉnh, thấu hiểu công việc và tính cách của bạn nữ. Không vồ vập, không sến súa tạo áp lực mà ghi điểm tuyệt đối nhờ sự chân thành và sáng tạo của một chàng kỹ sư IT.
- **Công nghệ & Trải nghiệm:** Web App tương tác di động (Mobile-First Interactive Web Experience) với hiệu ứng visual cao cấp, âm thanh du dương, mở hộp quà, thẻ cào voucher đặc quyền và tương tác gửi lời phản hồi.
- **Tiêu chuẩn mã nguồn:** Tuân thủ KISS, DRY, Modularization (< 200 lines/file), cấu trúc rõ ràng.

## 3. Cấu trúc thư mục
- `index.html`: Khung ứng dụng chính
- `css/`: Các file style được module hóa (variables, layout, components, animations)
- `js/`: Các module xử lý logic (audio, confetti, vouchers, typewriter, app)
- `assets/`: Hình ảnh, icons, âm thanh
- `plans/`: Kế hoạch và báo cáo thực thi theo quy chuẩn
